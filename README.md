# AIDUX: карта, маршруты, AR и AI

Один сервер, один порт (**5500**, меняется только в `.env`). Всё открывается через него.

## Запуск (Windows)
1. Установи Node.js 18+ (LTS) с https://nodejs.org
2. Распакуй архив в новую пустую папку и дважды кликни `start.bat`.
3. Первый раз он спросит ключ Gemini (https://aistudio.google.com/apikey): вставь и нажми Enter. Можно пропустить, тогда не будет только AI-чата.
4. Откроется http://localhost:5500/ai-chat.html. Карта: http://localhost:5500/map.html

Не Windows: `npm install`, затем `npm start`.
**Live Server (VS Code) не используй:** он занимает тот же порт 5500, и сервер напишет «Порт 5500 занят».
Проверка сервера: http://localhost:5500/health должен вернуть `{"ok":true,...}`.

## Настройка (`.env`, создаётся автоматически из `.env.example`)
- `PORT`: порт сервера (по умолчанию 5500).
- `CONTACT_EMAIL`: твой email для запросов к OSM-сервисам (требование их правил).
- `GEMINI_API_KEY`: нужен только для AI-чата. Без ключа карта, поиск и маршруты работают. Ключ лежит только в `.env`, не в HTML/JS, и не публикуй `.env`.

## Структура
- `server.js`: сервер. Раздаёт папку `public/`, API мест `/api/places`, `/api/suggest`, `/api/search`, AI `/ask`.
- `public/map.html` + `public/map.js`: карта (всё в одном скрипте).
- `public/ar-nav.html`: AR-навигация. `public/ai-chat.*`: чат. `public/vr.html`: 3D.

## Как работает карта
- Старт в Костанае. Кнопка «Моё местоположение» берёт GPS; если он неточный или не работает, нажми «Я здесь (на карте)» и отметь точку (метку можно перетащить).
- Адреса («Тауелсиздик 55/1») и названия («Март плаза») ищутся в радиусе ~40 км от центра карты. Кнопка «Искать по всему миру» появляется, только если рядом пусто.
- «Рядом»-поиск (кафе, аптеки и т.д.) считается от твоей точки.
- Маршруты: авто, пешком и велосипед строятся на отдельных серверах (routing.openstreetmap.de).

## Телефон и AR
Камере и GPS нужен HTTPS (на ПК подходит localhost). Для проверки на телефоне используй HTTPS-туннель или хостинг.

## Лимиты
Публичные Photon, Overpass и routing.openstreetmap.de подходят для разработки и небольшой нагрузки. Для публичного запуска поднимай свои.

## Публикация в интернет (доступ с телефона и любых устройств)
GitHub хранит только код и сервер на нём не запускает. Нужен хостинг для Node.js, например Render (файл `render.yaml` уже есть).
1. Залей проект на GitHub (без `.env` и `node_modules`).
2. На render.com: New → Blueprint (или Web Service) → выбери репозиторий.
3. В настройках сервиса задай переменные: `GEMINI_API_KEY` (твой ключ) и `CONTACT_EMAIL`. Ключ вводится только там, не в GitHub.
4. После деплоя сайт откроется по адресу вида `https://aidux.onrender.com/map.html`. HTTPS включён сам, поэтому GPS и камера на телефоне работают.
5. Защита ключа: не более 10 вопросов в минуту с одного устройства и `AI_DAILY_LIMIT` (300 по умолчанию) вопросов в сутки на весь сайт.
