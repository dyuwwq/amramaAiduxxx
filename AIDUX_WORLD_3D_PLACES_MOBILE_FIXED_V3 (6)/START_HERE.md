# AIDUX PRO MAX

1. Распакуй архив.
2. Открой папку в VS Code.
3. В терминале: `npm install`
4. Создай `.env` на основе `.env.example`.
5. Вставь свой API-ключ только в `.env`.
6. Запусти: `npm start`
7. Открой http://localhost:3000

Карта, AR и AI остаются отдельными модулями. Для камеры/GPS на телефоне в реальном интернете нужен HTTPS.


## Маршруты
Карта использует Nominatim/OpenStreetMap для поиска адресов и OSRM для построения автомобильных и пешеходных маршрутов. Для публичного проекта соблюдай лимиты и атрибуцию сервисов.

## Поиск мест рядом
На странице «3D-карта» добавлен отдельный поиск AIDUX Places: «Где поесть», «Бильярд», «День рождения», «Кофе», «Спорт» и «Развлечения». Поиск использует GPS пользователя, сортирует найденные места по расстоянию и позволяет выбрать место для маршрута. Если GPS запрещён, используется центр карты.
